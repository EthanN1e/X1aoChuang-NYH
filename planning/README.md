# STM32 手控云台立项与显示升级交付包

版本日期：2026-10-22。建议以本包中的升级版 Word 作为当前立项依据，早期 QGimbal/视觉方案不适用于本期。

## 内容

- 7 页 Word 立项书：目标、系统、彩屏、操作品质、验证、物料、进度和来源。
- 升级方案：代码审查证据、显示约束和功能优先级。
- 界面草案：三页静态 DEMO，不是已运行固件。
- 准备清单.csv：21 类物料，库存和报价待填写，可导入 Excel。
- DeepSeek任务：四项原仿真任务、四项显示评估任务、可复制总提示词及验收要求。
- 记录模板：空的日志、参数、测试与引脚资源表，附字段解释。

## 使用顺序

1. 查看 Word，补负责人、成员、启动日期；盘点原物料。
2. 核对显示实物型号、针脚、电平、尺寸和背光；按清单补报价。
3. 将 DeepSeek任务/提交与验收说明.md 与选定任务、升级方案、相关模板一起投递。
4. 需要本地原工程或 STL 的任务，按任务输入表另附选定文件。此包未复制原工程、STL 或联网配置。
5. 单模块验证后冻结接线与验收阈值，再做装配和对照试验。
