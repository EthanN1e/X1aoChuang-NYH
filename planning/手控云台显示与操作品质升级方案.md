# 手控云台显示与操作品质升级方案

日期：2026-10-22。范围：沿用原 STM32、3D 打印结构和 MG996R 的无发射机构手控台架；视觉识别为后续独立扩展。本文件为设计与静态代码审查，尚未移植、编译或在实物上验证。

## 1 显示模块识别与选型结论

`monitor/monitor.ino` 使用 Adafruit_ST7735 和硬件 SPI；setup 中 `initR(INITR_BLACKTAB)`、`setRotation(1)` 对应横屏 160×128 的软件配置。电路图中可见一块集成旋转编码器和按键的彩屏板，原主控标为 ESP32-C3 Super Mini。不能仅据图片确定屏幕尺寸、商品型号、孔距、背光电流与模块电源范围；“1.8 英寸”暂不能作为确认规格。

建议复用该型号屏幕及板载旋钮/按键，由原手柄 STM32 驱动。只移植显示界面，不引入原 monitor 的联网校时、环境监测、游戏等后台功能。若现有 monitor 已装配完成，也可保留作独立只读状态面板，作为备选方案；这会增加一块 MCU 及通信工作。

**采购/盘点描述：ST7735 系列 SPI TFT，原程序配置 128×160、横屏 160×128，带 A/B 两路旋转编码器、编码器按键及独立按键。优先复用同一实物模块；替代件按驱动、分辨率、电平、孔距和连接器逐项核对。**

## 2 接入约束

| 项目 | 当前证据 | 设计要求 |
|---|---|---|
| 屏幕数据线 | monitor 以 SPI 驱动，另有 CS、DC、RST | 移植到 STM32 的硬件 SPI，按本地工程及板卡实际走线重新分配 GPIO；ESP32 GPIO 编号不能照搬 |
| 原无线引脚 | 发射端 nRF24L01 软件 SPI 使用 PA0～PA4 | 不覆盖原无线引脚 |
| 原 IMU 引脚 | MPU6050 软件 I²C 使用 PB10/PB11 | 保留 IMU 接口 |
| 原 OLED | OLED 软件 I²C 使用 PB8/PB9 | 彩屏作为手柄主界面；旧 OLED 是否保留以空间和布线为准 |
| 原按键与定时器 | 按键 PB12；发射端也初始化舵机相关定时器 | 先做引脚/定时器占用表，不把“未看到使用”等同于可直接改线 |
| 显存 | 160×128×2 = 40960 字节的 RGB565 整屏缓存 | F103C8 SRAM 为 20 KB，使用局部绘制、小块缓存，查链接 map 与栈余量；避免整屏双缓冲 |
| 供电与背光 | 图片缺少完整的稳压、保护及背光参数 | 核实模块板的额定供电和逻辑电平；背光及舵机电流不直接由 MCU GPIO 承担；原图片不作为完整电源设计 |
| 屏幕刷新 | 主循环中增加绘图会占用处理时间 | 采样、无线处理与界面刷新各有独立节奏；只刷新变化区域，实测刷新开关前后的任务耗时 |

STM32 存储与 SPI 能力依据 ST 数据手册：https://www.st.com/resource/en/datasheet/stm32f103c8.pdf 。ST7735 初始化配置依据 Adafruit 源码：https://github.com/adafruit/Adafruit-ST7735-Library/blob/master/Adafruit_ST7735.cpp 。

## 3 屏幕应该显示什么

建议设置三页，旋钮切换页面、按压进入/确认，独立按键返回。首版旋钮用于菜单；本期不默认把它变成另一套运动输入。

| 页面 | 内容 | 数据含义和缺失处理 |
|---|---|---|
| 操作页 | 当前模式、手柄姿态、指令角度、IMU 状态、无线发送统计 | 姿态和指令分开标注；没有传感器反馈时，实际云台角度显示“未接入” |
| 诊断页 | IMU 有效样本数、读取错误数、样本年龄、无线统计窗口、界面刷新耗时 | 显示测量窗口；错误/过期数据不继续伪装成实时数据 |
| 设置页 | 显示亮度、单位/方向提示、参数版本、校准记录、恢复默认入口 | 参数改动有确认、范围检查和版本记录；故障提示不能只依赖颜色 |

原 nRF24L01 发送成功/ACK 可以表明无线链路的一部分状态，但不能证明舵机已运动到指定位置。接收端状态若要在手柄显示，需要新增并验证应用层回传；现有程序没有云台实际角度遥测。电池电压需要测量电路与校准，不能凭电池标称值生成百分比。

首版界面优先简短英文标签和数字（与现有 monitor 图形库一致）；若采用中文，仅加入所需字符字模并核查 Flash 占用。随附界面图为静态示例，数据全部为演示值。

## 4 手柄准确度先拆成四类指标

1. **静止稳定性**：手柄固定不动时，姿态读数变化多大；同时记录有效样本比例，不能删除异常后只报平滑结果。
2. **操作重复性**：用独立角度夹具重复回到同一姿态，比较读数；仅凭软件显示自身不能证明准确。
3. **响应一致性**：相同动作的显示延迟、无线数据年龄是否一致；增加屏幕后是否发生明显变化。
4. **机械输出一致性**：用独立量角或测量工具记录中性载荷实际位置，与指令分开比较；MG996R 内部控制不等于 STM32 已获得实际角度。

本期先建立上述基线，再制定验收阈值。没有实测不能承诺“0.1°精度”或某个百分比的性能提升。

## 5 静态审查发现及改进顺序

| 优先级 | 发现/待评估问题 | 本期安排 |
|---|---|---|
| P0 | 发射端 main.c 将 DMP 读取返回值存入 ac，但没有判断 | 先建立有效样本、失败和过期状态，作为显示与试验记录的基础 |
| P0 | 接收端 main.c 区分成功/失败计数后，仍在同一个 ReceiveFlag 非零分支使用数据 | 纳入异常输入行为审查，在无负载台架验证；不把接收失败记成正常动作 |
| P0 | DMP_Init 内多个初始化调用缺少完整错误传播，函数末尾固定返回 0 | 上电自检状态必须反映真实结果，不只显示“初始化完成” |
| P1 | 发射端姿态转为 uint8_t 后发送，丢失小数信息 | 记录量化前后差异，区分输入数据分辨率和机械准确度；不能只增加显示小数位就宣称精度提升 |
| P1 | 原代码使用 Roll 与 Yaw 字段，用户动作和物理轴的对应需实测 | 增加清楚的方向标识、固定安装姿态和一致的手柄握持基准 |
| P1 | 原手柄没有明确的上电基准流程及校准结果显示 | 增加可见的静置/校准进度、成功/失败提示和记录；具体参数依据台架数据确定 |
| P1 | 六轴 IMU 的角度稳定性依赖姿态估计与参考条件 | 做短时/长时静止漂移对比；不能仅凭平滑曲线认为长期方向准确 |
| P1 | 打印件松动、舵机间隙、载荷偏心及供电变化可能影响输出 | 先检查刚度、紧固、负载和供电，再判断输入算法改善是否有效 |
| P2 | 手柄握持疲劳、按键误触、旋钮操作影响姿态 | 优化屏幕倾角、拇指可达性、握把表面和按键位置；通过重复操作试验验证 |
| P2 | 数据缺少可复现的记录方式 | 加入只读日志导出及参数版本信息，便于比较修改前后 |

首轮以“能看清、能记录、能发现异常、重复操作一致”为目标。平滑、灵敏度或微调等操作方案应在中性载荷台架取得基线后再评估；本文件不提供发射装置的瞄准性能优化、控制增益或联动代码。

## 6 追加物料与验证顺序

| 物料 | 建议数量 | 说明 |
|---|---:|---|
| 同款 ST7735 旋钮彩屏模块 | 1 | 已有则复用；确认模块型号、额定值、孔位 |
| 屏幕支架/手柄上盖 | 1 套 | 结合原 3D 打印手柄重新测量，检查重量和重心 |
| 可靠连接器及软线 | 1 套 | 按实际模块接口选择，预留拔插和应力释放 |
| 独立返回键 | 0～1 | 同款模块已带则不重复购买 |
| 固定角度夹具或独立角度测量工具 | 1 套 | 用于重复性评价，作为测量参考 |
| 万用表、逻辑分析工具 | 复用/借用 | 电源与刷新占时验证按需要使用 |
| 电池测量电路 | 条件项 | 需要电量页时单独设计、验证；不是直接接电池到 ADC |

验证顺序：屏幕单独点亮与显示测试 → 编码器/按键离线菜单 → 合成数据状态页 → IMU 只读数据 → 无线状态记录 → 无发射机构台架对照测试。每阶段保留失败样例，完成一项再增加下一项。

## 7 源码证据位置

- monitor/monitor.ino：1–37 行为库与硬件声明；1117–1133 行为显示初始化；161–174 行附近为按键处理（多个按键共用一个时间变量，移植时需评估互相抑制的体验）。
- 发射端/User/main.c：39 行读取姿态；56–58 行转整数；71–74 行填无线包。
- 发射端/MPU6050DMP/inv_mpu.c：2886–2903 行初始化；2912–2941 行姿态读取及返回值。
- 接收端/User/main.c：43–68 行接收状态处理与数据使用。
- 发射端/Hardware/OLED.c 与 NRF24L01.c、MPU6050DMP/MPU6050_I2C.h：原引脚占用。

本方案未修改用户的原程序和原图。任务包只包含新写的设计任务与示例数据，不复制 monitor 的联网配置。
