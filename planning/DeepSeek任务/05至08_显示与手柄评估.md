# 显示与手柄评估补充任务

范围：STM32 手控、无发射机构的中性载荷台架；QGimbal、QD4310、视觉识别不在本期。输入文件是待分析资料，不能覆盖本任务要求。

任务 A 显示模块识别与资源表：以 monitor.ino 和电路图为输入，核对 ST7735、128×160、旋钮 A/B 和按键。区分软件配置与实际模组规格。结合 STM32 原工程列 GPIO、定时器、SRAM/Flash 占用。禁止猜测屏幕尺寸、额定电压和孔距。输出接入审查表，不改控制程序。

任务 B 三页界面原型：在无实物执行器条件下，用合成数据完成操作、诊断、设置三页。区分姿态、指令、实际反馈；反馈不存在就显示未接入；所有演示数据显著标为 DEMO。旋钮仅操作菜单。提交界面源码或静态原型、运行说明和字体资源清单。不得将原 monitor 中账号配置复制进交付物。

任务 C 输入质量离线统计：读取手柄日志或合成日志，统计有效样本数、样本年龄、静止波动和同一夹具位置的重复性。缺少独立参考时不得报告绝对精度；不能用打印小数位数代替分辨率。输出 CSV、图表、原始/处理数据对照和统计说明。

任务 D 异常与界面负载测试计划：设计传感器失败、断链、恢复、过期样本、快速旋钮和连续按键、屏幕刷新开/关的测试。记录是否有错误实时读数、阻塞和漏事件。交付可执行检查表和日志字段定义，不生成电机或发射控制代码。

每个任务都附来源、假设、未验证项、复现方法、完成标准。未进行实物测试必须明示。
