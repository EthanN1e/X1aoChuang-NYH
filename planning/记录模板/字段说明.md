# 记录字段说明

所有 CSV 模板只有表头，不包含实测数据。缺少的数值留空，不能用 0 替代未知。CSV 使用 UTF-8 BOM，可用 Excel 导入。

- run_id：一次独立试验标识；data_origin 只能是 measured 或 synthetic。合成记录不得混入实测统计。
- clock_domain：时间来源标识。t_ms 为该时基下单调时间；设备重启另起 run_id。不同设备时基不能未经同步直接相减。
- sample_seq：记录序号；若来自原 uint8 包序号，必须注明回绕规则，不能把回绕当乱序或巨量丢包。
- imu_valid：1 有效、0 无效。imu_error_code 保留原错误码。sample_age_ms 为当前时间与最近有效采样时间之差；未初始化时留空。
- roll_deg/yaw_deg：姿态读数；cmd_a_deg/cmd_b_deg 为日志中的指令观测值，不能解释为实际到位角度。此模板不定义新控制算法。
- tx_result：本地发送状态；接收端确认和执行器反馈必须另建字段，不混用。
- ui_duration_us：单次界面任务耗时；统计时同时报告窗口与极端值。
- fixture_id/reference_angle_deg/reference_uncertainty_deg：独立夹具位置、参考角度与测量不确定性。缺少独立参考时只能报告稳定性或重复性。
- supply_v：有实际测量时填写，不用电池标称电压代替。
- 准备清单所需量是文字说明；库存待盘点。采购量需在规格核对和库存确认后填写。
