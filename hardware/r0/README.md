# R0 集成 PCB

| 文件 | 用途 |
| --- | --- |
| [gimbal-r0.epro2](gimbal-r0.epro2) | 嘉立创 EDA 专业版工程，包含三页原理图和 PCB1 |

| [pcb1-drc.json](pcb1-drc.json) | 保存并重载后得到的原生 DRC 记录，0 项违规 |

同版四层裸板 56 × 80 mm，一套用两块。手柄端装 63 件，包含 MPU-6050、1S 充电和 3.3 V 稳压。云台端装 36 件，接两只位置型舵机，由 J12 输入共地的稳压 3.3 V 和舵机电源。两端各接一个 nRF24L01+ 模块。R7、R26、J13 默认留空。

J6 预留带按压的 A/B 增量编码器，J5 接 ST7735 屏。屏幕与无线模块针序、外壳尺寸、舵机电流和供电余量待实物核对。R0 固件适配和两端联调仍待完成。
